# Industrial UI polish - design and implementation plan

User direction: DOOM-inspired industrial panels and compact headings; user delegates visual decisions, requests safe shared integration and an update after every push.

## Design
Graphite/navy opaque-enough surfaces, warm ivory reading text, restrained mustard focus and primary actions. Barlow Semi Condensed for headings and Roboto for body. Role colours and all science/story content remain. 4 px corners replace the old 12 px rounding. Clear 2 px focus outline, comfortable 48 px actions, low-noise backgrounds, 150% text and scroll/focus reflow.

Keep the house UiDesign/UiKit APIs and rebuild their saved Theme so existing panels inherit the change. Use installed Gohud sci-fi surface styling in the authored title composition without replacing gameplay contracts. The main menu composition is serialized in main_menu.tscn with a scrollable navigation column and a cinematic right-hand image from the already-approved CS-01 exterior. Title says New expedition, Continue, training, chapter progress; utility actions retain their public signals.

Alternatives considered: recolour-only would leave the crowded title; replacing every panel with Gohud would overlap active settings/HUD work and risk interaction regressions. Chosen: shared foundation plus a fully composed title, preserving all existing signal/query/save APIs. No new assets are generated; the title image is an extraction from approved cutscene footage with its terrain credit.
