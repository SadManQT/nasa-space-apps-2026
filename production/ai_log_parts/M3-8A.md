# M3-8A — Chapter 8 assets, phase 1: the five approval sheets (Sadman/claude, 7 Nov 2026)

Board task M3-8A (EN_MalapertSummit, EN_RelayRoad, EN_NoorRooftop, CH_Noor, CH_Rao), phase 1 only: 2D sheets for
Sadman's approval; no 3D credit before approval (CLAUDE.md). Tools: Claude Code (Claude Opus 5.5, claude-opus-5-5,
extra-high effort) wrote every script, reviewed every image and wrote the decisions; Tripo CLI 0.8.1 `image` on the web
plan (`default` profile) made the character images; Blender 5.2.2 Cycles rendered the environments (procedural, no AI);
Python 3 with Pillow, numpy and SciPy composed the sheets.

**Credits.** Tripo web plan: 810 before the first generation and 810 after the last (read before and after every call;
the image tool did not charge, as on 5-6 Nov). No Tripo or Meshy 3D credit, no ElevenLabs, no money.

**Environments: no generation.** The summit, road and rooftop sheets are Blender Cycles renders of procedural geometry
(`production/concept/chapter8_v1/build_*.py`) on NASA LOLA terrain (PGDA Site23 5 m, malapert_vista 40 m, LDEM_80S_40MPP
round R2, the 80 m relay corridor; all already cached, nothing fetched) under the JPL Horizons rows in
`sun_positions.json`. Reused installed assets: VH_Rover (both lunar scenes), PL_Tara_Bloom (the rooftop mustard), the
M1-35 regolith textures and rock forms.
