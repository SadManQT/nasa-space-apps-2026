## Public contract (for the Class UI, M1-37)
- `Main._start_new_expedition(crew := {"mode": "solo", "players": 1})` and static `Main.build_new_expedition_snapshot(crew)`: validated fresh crew (`mode` solo or class, `players` an integer, class needs 2 to 4; unknown keys, wrong types and other modes are rejected before any existing save is replaced). The title's zero-argument signal still starts Solo.
- The crew is stored in the existing save store and survives Continue and gameplay retry; legacy saves restore as Solo.
- `Chapter1Route.team_plan_view(target_id)`: primitive read-only view of the P-02 selection, forecast, revision and crew roles for private role cards.
- `Chapter1Route.sign_team_plan(role_id, target_id, reviewed_selection)`: signs only a selection that still matches the live model, forecast, revision and crew; a physical USE with the default payload cannot bypass the Class confirmation; stale or malformed sign-offs are refused; no missing provider ever auto-signs.
- Sign-offs are route evidence, not simulation input; each record names crew, scene, state revision, selected plan and forecast.
