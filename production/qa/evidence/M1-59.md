
That renders the 22 specs one at a time through `production/tools/godot_gated`. It removes each clip from

`build.py dump specs/<id>.json` against the new UI for any spec whose `verify` note asks for it (puzzle-panel
choice buttons, the payload walk), and look at every sheet.

## Pipeline

| Piece | File |
|---|---|
| Director: builds the real campaign (or Moon Trainer, or the Care Round panel) at a scene, drives it with scripted input (`hold`, `key`, `click`, `call`, `perform`, `payload`, `near`, `scroll_to`) and draws the ring, arrow, key, pointer, caption, chip and progress overlays; `--dump` lists the visible named controls, `--still` saves one screenshot | `production/explainers/howto/director.gd` |
| Build: `check` (8–20 s, captions ≥ 1.8 s and ≤ 16 words, cards exist, English only), `dump`, `render` (Movie Maker → PNG frames → last `length_s × 24` frames → `production/tools/ogv_writer.gd` → `.ogv` → registry), `pending` | `production/explainers/howto/build.py` |
| One spec per clip | `production/explainers/howto/specs/<id>.json` |
| Clips | `game/assets/explainers/<id>.ogv` |
| Registry | `game/resources/campaign/content/explainers.json` (kind `how_to`, level `method`; `pending_render` list) |

Film size: **1280×720 at 24 fps**, not 1152×648. The project's `window/size/window_width_override=1280` pins the
Movie Maker size, and every cutscene and science explainer in the repo is 1280×720 (STYLE.md calls it the project
film size), so the how-to clips match them. Silent clips get a silent WAV for `ogv_writer.gd`.

## First-time cards, guided first use, Journal How to

- `how_to.json`: 26 cards; `mechanics` lists the 23 card ids for doc 25's 22 mechanics (moving and looking share a
  clip). Each card has `title`, `purpose`, ≤ 3 `steps`, `how_clip`, `nudge` (the guided first use), `chapter` and,
  except for the four the code raises itself (move, look, use, mission_table), `first_targets`.
- The card (hint player, `how_to` mode) shows the purpose, the steps, the how-to clip playing inline with captions
  and Pause/Replay, then "Try it now: …" and a "Try it now" close button on first use; "Watch the science" opens
  the science explainer when the card has one. Always skippable (Esc / B).
- `chapter1_campaign_hud.gd` (+2 lines in `_apply_goal`): when the goal becomes a mechanic's first target, its
  first-time card is queued through the existing `offer_first_time`.
- Journal → Now → **HOW TO**: one replay button per mechanic reached so far (chapter ≤ current), no spoilers.
- `game/scripts/ui/how_to_card.gd`: `mechanics()`, `first_time_for()`, `reached()`.

Screens: `M1-59_first_time_card.png` (first-time Move card with the clip playing), `M1-59_journal_how_to.png`.
