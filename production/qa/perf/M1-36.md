## Interface for the room owner

Add a stream Node3D to the intended site's local coordinate frame, then call `configure(region_id, local_start, clear_areas) -> bool` while under the tree. Clear areas use the existing scatter exclusion schema. `move_focus(local_position) -> bool` streams the near collision/rock rings and requests mesh LOD changes. Coordinates must be finite and inside the hero heightfield. Invalid initial calls are retryable; an already configured stream cannot silently change regions. `lighting(scene_id) -> Node3D` returns the dated hard-Sun/black-environment rig using the bundled ephemeris, or null for a scene from another site. Negative Sun elevations are retained. Inspect the rig's `ephemeris` metadata for Earth visibility; Earth artwork is not supplied here.

M1-82 must publish the terrain-to-room transform, reachable door/prop/target anchors and scatter clear areas, disable only obsolete staging floors through an explicit hook, and supply scientifically placed Earth presentation. Atik can then wire the campaign/loading lifecycle and camera far plane. Do not place real heights beneath the current flat rooms without relocating their collision and interactable anchors. Preserve airlocks, pressure checks, room joins and all existing authored props.

The provider initially installs one coarse mesh per hero tile during loading, then publishes at most one asynchronous LOD replacement per frame, with hysteresis. A root-owned request drain consumes successful threaded requests exactly once, including after terrain teardown or timeout. Nearby heightmap collision and rock chunks remain bounded. The profile is `game/resources/campaign/profiles/terrain_stream.json`. Fresh regolith replaces inappropriate compacted-track detail, and runtime texture copies receive mipmaps without changing shared import settings.
