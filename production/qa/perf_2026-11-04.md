## Proven causes and changes

1. **Review-grade CPU skinning in the gameplay hot loop.** `game/scripts/player/locomotion_pose.gd:118` and `:184` formerly called the full `FootSlide.sample()` twice per character per physics tick. `game/scripts/review/foot_slide.gd:119` transforms every boot vertex, allocates per-surface position/history arrays, and calculates velocity/contact statistics. IK consumes only the two minimum heights. With five characters this repeatedly exceeded the CPU frame budget. Added `sample_heights()` at `foot_slide.gd:97`: flat packed arrays, every original boot vertex/influence retained, and only the world-space Y row evaluated. IK calls that path now; the full review sampler remains available. Full-cast isolated per-call p95 fell **3.839 → 0.692 ms**. Both height queries remain; skipping the post-rotation query would change foot clearance.

2. **Synchronous raw glTF decoding repeated on every room reconstruction.** `game/scripts/campaign/chapter1_campaign.gd:448` rebuilds the room; `game/scripts/world/campaign_room.gd:280` loads each model. `game/scripts/asset_geometry.gd:20` uses `GLTFDocument.append_from_file()` / `generate_scene()` with uncompressed embedded images. The old player duplicated that same importer. Added an **8-entry LRU** of parsed PackedScenes (`asset_geometry.gd:7`), invalidated by source modification time, and routed character loading through it (`player_controller.gd:66`). Skeletons and node state are instantiated independently; immutable geometry/textures are shared. Repeated greenhouse construction fell **336.413 → 2.229 ms**. Source GLBs, texture resolution, shaders and outlines are unchanged. Evicted scenes can still be held by live instances; the cap bounds cached scene count, not total live memory.

3. **Fresh gait analysis during character construction.** `game/scripts/player/locomotion_clips.gd:122` samples each gait at 120 Hz and performs full boot/contact skinning to derive speed and cycle boundaries. All characters did this synchronously in `_ready()`. Five tiny JSON files in `game/resources/player/gaits/` now hold exactly those derived results; `locomotion_clips.gd:69` validates the source SHA-256 and bake version before using them. Missing/stale bakes fall back to the original analysis. Cubic cycle generation and all tuning remain unchanged. Bake precision uses full-precision JSON. Rebuild with `Godot --headless --path game --script res://tools/bake_locomotion.gd`; increment BAKE_VERSION if measurement/cycle algorithms change. The optional source path flows through `player_animation.gd:44` and `player_controller.gd:91`. No design arithmetic moved into code.

## Other suspects checked

- [Engine settings](evidence/perf_2026-11-04/engine_settings.txt): VSync enabled (`1`), max_fps `0` (uncapped), physics 60 Hz, pipeline cache and shader cache enabled, MSAA disabled, TAA disabled. No quality settings changed. Shader/pipeline first-use stalls remain **NOT ASSESSED** without a rendering run; no speculative prewarming added.
- `room_presentation.gd:34–65`: simple color environment, fog/volumetric fog explicitly off, one shadow-casting directional key and an unshadowed fill. No campaign SDFGI/VoxelGI/SSR/SSIL stack or shadow-casting omni/spot-light crowd was found. `environments/look/character_look.tres:21–32` enables SSAO/SSIL for the title/look stage; retained for appearance. GPU cost is unmeasured.
- GLB header/image inspection: cast approximately **58–61k triangles each**, three 4096² body maps each; Mission Table 20k triangles and Growth Chamber 25k, with 2048² maps. Import descriptors enable LODs/shadow meshes/Basis handling, but the raw runtime GLTF loader bypasses the editor-imported scene, so those import flags do not establish runtime LOD/compression. `toon_materials.gd:79` already generates mipmaps for raw albedo/normal ImageTextures. No texture downscaling, compression change, decimation or outline removal performed. Occlusion culling is off; no measured evidence supports changing it here.
- `campaign_crew.gd:23–27` already disables processing on hidden actors. Visible animations/IK continue intentionally. `chapter1_campaign.gd:235` does query nearby targets each physics tick, including deep state copies; this is a remaining CPU candidate, but the measured post-fix total is below 7 ms and no further change was justified. Forecast reconstruction is guarded by scene/target/state-revision key (`chapter1_campaign_hud.gd:502–510`). Group scans happen on interact, not continuously (`player_controller.gd:267–282`). No per-frame signal reconnect or print loop found; stride/root logs occur on setup.
- Campaign cutscenes currently provide plans/captions (`cutscene_runtime.gd:43`), while the development showcase owns actual `VideoStreamPlayer` playback (`asset_showcase.gd:351`). The probe exercises that native decoder path with the installed files; rendered decode/presentation results remain unmeasured. No reserved audio/cutscene source files were edited.
