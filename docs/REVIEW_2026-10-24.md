# Design review · 24 October 2026

**What was reviewed:** everything on `main` after Atik's `game-design/` upload (46 files) and Sayem's final docs
(story, gameplay, game plan, science, competition rules, update requirements), checked against each other.
**Method:** every file read; the P-02 rules run over all 528 billion possible Chapter 1 plans
(details in [P02_BALANCE_CHECK.md](P02_BALANCE_CHECK.md)). Nothing in the team's files was edited; this page lists
what to fix. Paths in `game-design/` are shortened: `S/` = `game-design/06_SCENE_SCRIPTS/`.

**Overall:** the story is warm, coherent and age-appropriate, and the science labelling is now honest. The Chapter 1
numbers are correct (all four worked plans reproduce exactly). The main risks are the **competition rule on pre-event
work**, a **much shorter real build window** than planned, a few **rule holes in P-02**, **story leaks** of the
Chapter 5 secret, and **out-of-date documents** that still describe the old 2D web game.

## 2. Competition and submission risks

- **Real build window is ~11.5 hours to the first demo.** Video 2 needs *"a demo of it working"* by 6:30 PM on 13 Nov,
  and the event starts at 7 AM (competition-rules.md §A, §B). `18_TECHNICAL_BLUEPRINT.md` and the hour-24 rule in
  GAME_PLAN_FINAL §11 assume 48 hours. Plan a playable greybox by about 5 PM on day 1.
- **AI disclosure:** every tool, prompt, reason and the team's own contribution must be listed (rules §E). The
  declaration log in ASSETS.md now has those columns; `14_ASSET_PRODUCTION_LIST.md` has none.
- **Licensing:** raw Mixamo FBX files should not go in the public repo; check the Tripo, Meshy and ElevenLabs plan
  terms before releasing under Apache 2.0 (rules §E).
- **NASA branding:** GAME_PLAN_FINAL plans a "NASA-style patch"; make it original, with "not endorsed by NASA".
- **NASA data in live play:** judges score *"how deeply NASA data sits at the core"*. In `18_TECHNICAL_BLUEPRINT.md`
  the data only changes a debrief comparison. Feed at least one processed value into the live mission (for example
  the CRaTER curve shaping the storm, which would also fix D4).
- **Minors:** no recognisable under-18 voices in videos (rules §E). GAME_PLAN_FINAL §12 says "the team records the
  voices"; make sure no under-18 team member is recorded.
- **Repo for judges:** the pitch MP4 is stored in Git LFS (a pointer file in clones); ship the build through GitHub
  Releases so judges never hit LFS limits.
